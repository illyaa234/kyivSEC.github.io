# Cybersecurity landing (KyivSec)

Статичний односторінковий сайт (HTML/CSS/JS) українською мовою.

## Запуск

Найпростіше відкрити `cybersec-site/index.html` у браузері.

Для локального сервера (щоб коректно працювали деякі браузерні політики) можна:

```powershell
cd cybersec-site
python -m http.server 5173
```

Потім відкрийте `http://localhost:5173`.

## Налаштування під себе

- Заміна назви/емейлу: `cybersec-site/index.html`
- Стилі: `cybersec-site/styles.css`
- Логіка меню/форми: `cybersec-site/app.js`
